# Security

AI Security Reconnaissance Agent gives a model access to a persistent shell and file editor. Its persona is not an enforcement mechanism. Run only trusted presets, use a dedicated environment, and keep the server on loopback unless separately secured.

Do not include credentials, cookies, personal data, private target reports, or exploit payloads in public issues. Once hosted on GitHub, use private vulnerability reporting if the repository owner has enabled it. Otherwise contact the maintainer privately before disclosing sensitive details. Never publish a vulnerability report solely because a private reporting channel is not configured.

Support currently targets the pinned DeepSeek Harness version documented in the README. Upstream security fixes and compatibility changes require explicit dependency review and regression testing.
